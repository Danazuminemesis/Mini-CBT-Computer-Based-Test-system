# Mini-CBT-(Computer-Based-Test)-system

## Project Overview
The CBT System is a simple web-based Computer-Based Test application built using Python and Flask. It allows users to take a test, select answers, and receive their score instantly.

---

## Features
- Multiple choice questions
- Automatic scoring system
- Displays total score after submission
- Shows time of submission
- Performance feedback (Excellent, Good, Try Again)
- Dark-themed user interface

---

## Technologies Used
- Python
- Flask
- HTML & CSS
- datetime module

---

## How It Works
1. User clicks "Start Test"
2. Questions are displayed
3. User selects one answer per question
4. System calculates score
5. Result is displayed with feedback
